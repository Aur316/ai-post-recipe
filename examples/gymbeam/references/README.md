# GymBeam reference images

Put the reference images for the demo here. `pnpm seed:demo` uploads every image in this folder with the GymBeam brief. The file name decides the kind:

| File name starts with | Kind                 | Used for                                            |
| --------------------- | -------------------- | --------------------------------------------------- |
| `logo`                | Logo                 | The header of every slide; colours for the analysis |
| `product`             | Product photo        | The first slide of each post, in file-name order    |
| `screenshot`          | Instagram screenshot | The analysis: tone, colours, visual style           |
| anything else         | Other reference      | The analysis                                        |

PNG, JPEG or WebP (SVG for the logo), up to 10 MB each. Product photos on a transparent background look best on the slides.
