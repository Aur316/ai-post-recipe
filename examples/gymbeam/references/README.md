# GymBeam reference images

The reference images of the GymBeam demo. Upload them in the brief form (see [the recipe](../../../docs/recipe.md)); for developers, `pnpm seed:demo` loads them with the brief. The file name suggests the kind:

| File name starts with | Kind                 | Used for                                                            |
| --------------------- | -------------------- | ------------------------------------------------------------------- |
| `logo`                | Logo                 | The header of every slide; colours for the analysis                 |
| `product`             | Product photo        | Placed in the post's scene by the image model, in the brief's order |
| `screenshot`          | Instagram screenshot | The analysis: tone, colours, visual style                           |
| anything else         | Other reference      | The analysis                                                        |

PNG, JPEG or WebP (SVG for the logo), up to 10 MB each. A clear front view of the packaging works best, because the label is copied from it.
